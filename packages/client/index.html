Управление
  • ЛКМ по космосу — лететь (нужен пилот: он садится за мостик сам).
  • ЛКМ по объекту — выбрать: атаковать, добывать, высадиться, торговать.
  • Колесо — масштаб; отдалитесь — перейдёте в «Звёздную систему».
  • Tab / Пробел — корабль ⇄ звёздная система.
  • B — строительство, C — команда, O — воздух по комнатам, G — галактика.
  • Протяжка мышью — пол и разбор прямоугольником, стены — рамкой.
  • ПКМ — отменить инструмент/выбор. Shift+ЛКМ по модулю — вкл/выкл.
  • Пробоина выпускает воздух, пожар без воздуха гаснет. Криокапсула спасает от голода и удушья.
STARFORCE
